# Source content

Reference copy provided by the branch, kept here so it is easy to find. **These files are not loaded by the website.**

| File | Contents |
| --- | --- |
| `general-description.tr.txt` | Long "About IEEE / IEEE TEDU" text (Turkish) |
| `short-descriptions.tr.txt` | Taglines and one-line descriptions per committee (Turkish) |
| `committee-descriptions.tr.txt` | Longer descriptions and mottos per committee (Turkish) |
| `social-media-links.txt` | Instagram and LinkedIn accounts |

Text shown on the site lives in `assets/js/i18n/tr.js` and `assets/js/i18n/en.js`. When you use copy from these files on the site, add it there in both languages.
